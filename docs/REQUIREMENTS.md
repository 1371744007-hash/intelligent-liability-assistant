# 需求说明

本项目是用于学习与求职展示的“逆向保价智能判责助手”网页 Demo，仅使用模拟订单、模拟案件和模拟业务规则，不连接公司内部系统。

## 范围

- 模拟订单选择及跟单信息回填，明确区分“无”和“未知”。
- 商家报案文本输入、多图片上传、预览、删除和材料类型标注。
- 页面一键填入覆盖 R001–R008 的演示案例；边界案例只保留在测试数据和测试文档中，不在演示下拉框展示。
- 支持自定义模拟报案，填写商品、验货服务状态、勾选验货项目及录入验货结果。
- 服务端将规则、商家描述、系统记录及图片提交给支持图片输入的模型。
- 展示结构化的责任、赔付、追偿、命中规则、依据、图片现象、缺失/矛盾和人工原因。
- 服务端校验枚举值和业务一致性；无法可靠校验时转人工或明确报错。
- 页面可查看完整模拟规则。

## 不在范围内

- 不计算或执行赔付、追偿，不接真实业务系统。
- 不使用 RAG、向量数据库或复杂 Agent 框架。
- 不展示无校准依据的置信度。
- 未配置 API 时不模拟或伪造 AI 结果。

## 安全与证据原则

- 报案文本与图片内的指令一律视为待分析材料，不能覆盖系统规则。
- 区分商家陈述、系统记录、图片可见现象与未证实推断。
- 图片无法支持的损坏时间、责任主体或真伪均标为未知。
