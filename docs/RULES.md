# 模拟业务规则

> 以下规则仅用于本项目，不是通用保险条款。应根据案件事实匹配，商家单方声称不等于事实已证实。

- **R001 商家责任**：去程收货时已发现损坏，随后退回，且同一损坏被报案。商家责；不赔付；不追偿。必须确认去程已损坏且是同一损坏。
- **R002 用户退回自有相似商品**：证据确认并非同一件，且差异超出物流验货识别能力。用户责；赔付；不追偿。仅凭外观相似图片不足时转人工。
- **R003 用户使用痕迹**：证据支持用户使用造成划痕、脏污或塑封拆除。用户责；赔付。验货服务且项目覆盖对应问题则追偿；无服务或不覆盖则不追偿；验货信息缺失则追偿待确认；验货记录与材料矛盾则转人工。划痕、脏污、塑封须分别对应。
- **R004 物流运输破损**：外包装挤压/破损且商品本身或内物包装破损，无已确认的其他优先具体原因。物流责；赔付；追偿。
- **R005 物流错件**：证据支持物流人员操作导致错件。物流责；赔付；追偿。不同商品也可能是用户退错，原因不明转人工。
- **R006 天灾损坏**：证据支持运输中因天灾损坏。保险责；赔付；不追偿。仅提到下雨不足。
- **R007 高仿假货**：足够材料确认高仿假货。保险责；赔付；不追偿。普通照片或单方怀疑不足时转人工。
- **R008 外包装完好、内物破损**：确认外包装无挤压破损，但商品本身破损，且无其他已确认具体原因。保险责；赔付；不追偿。未上传外包装照片不等于包装完好。

## 补充规则

1. 商家责不赔付、不追偿。
2. 用户责、物流责、保险责均赔付。
3. 追偿按具体场景判断，不得写成“有保价就追偿”。
4. 本版本不处理金额，保价及运费倍数不参与金额计算。
5. 优先检查证据支持的具体原因，包装外观不能覆盖明确的去程损坏、用户使用、天灾等原因。
6. 多规则同时适用且结论不同、规则未覆盖或证据不足时转人工，不自行发明优先级。
7. 责任可确定而追偿条件不明时，可确定责任和赔付，追偿标记待确认。
